### 🌟 Featured Projects

#### 🔬 [VisionLab – Real-Time Image Enhancement](https://github.com/SweetRomeo/VisionLab)

A Master's thesis project investigating the performance and suitability of different software architectures for real-time image enhancement and autonomous-vehicle vision systems.

* **Architectures:** Pure Python, Hybrid Python+C++ and Pure C++
* **Technologies:** C++17, Python, Qt 6, OpenCV, PyBind11 and CMake
* **Algorithms:** Gamma Correction, Histogram Equalization and CLAHE
* **Evaluation:** Processing latency, effective FPS, deadline compliance, dropped frames, resource utilization and output equivalence
* **Experiment design:** Multi-resolution reproducible benchmarks and a controlled-illumination protocol based on lux levels and light-incidence angles
* **Current status:** Desktop reference benchmarks and real-time pipeline evaluation completed
* **Next phase:** Controlled-lighting experiments and deployment evaluation on Raspberry Pi and NVIDIA Jetson platforms

#### ☕ [Video2Quiz](https://github.com/SweetRomeo/Engrare-Interview-App)

A backend application that processes video content to generate interactive quizzes using the Java and Spring ecosystem.

* **Focus:** Backend architecture and RESTful API design
* **Tech Stack:** Java, Spring Boot and Maven

#### 🏛️ [Alexandria – Library Management System](https://github.com/SweetRomeo/Alexandria)

### 🔬 Current Master's Research

My research examines how software architecture affects the real-time performance of image-enhancement pipelines.

The study compares:

* Pure Python
* Hybrid Python+C++ using PyBind11
* Pure C++

The current research infrastructure includes:

* Shared and reproducible benchmark configurations
* Multi-resolution and multi-algorithm experiments
* Release-mode benchmark enforcement
* Cross-architecture output-equivalence validation
* Processing and end-to-end latency measurements
* Deadline-miss, dropped-frame and skipped-frame analysis
* CPU and memory resource monitoring
* Automated statistical summaries and visualizations
* Experiment environment and dependency metadata
* A controlled-illumination evaluation protocol

The next experimental phase will evaluate these architectures under measured illumination levels and incidence angles, followed by embedded-platform testing on Raspberry Pi and NVIDIA Jetson hardware.
